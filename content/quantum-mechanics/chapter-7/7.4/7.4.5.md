# Shankar §7.4 Exercises 7.4.1–7.4.7

## Unified prerequisites: inputs not derived inside these exercises

### ① Orthonormal number basis
\[
\langle n'|n\rangle=\delta_{n'n},\qquad n=0,1,2,\ldots
\]

### ② Expectation value and variance
\[
\langle A\rangle=\langle\psi|A|\psi\rangle,\qquad
(\Delta A)^2=\langle A^2\rangle-\langle A\rangle^2.
\]

### ③ Canonical commutator
\[
[X,P]=i\hbar I.
\]

### ④ Commutator identities
\[
[A,B]=AB-BA,
\]
\[
[AB,C]=A[B,C]+[A,C]B,
\]
\[
[A,BC]=[A,B]C+B[A,C].
\]

### ⑤ Harmonic-oscillator Hamiltonian
\[
H=\frac{P^2}{2m}+\frac12m\omega^2X^2.
\]

### ⑥ Ladder operators
\[
a=\sqrt{\frac{m\omega}{2\hbar}}X+
\frac{i}{\sqrt{2m\hbar\omega}}P,
\]
\[
a^\dagger=\sqrt{\frac{m\omega}{2\hbar}}X-
\frac{i}{\sqrt{2m\hbar\omega}}P.
\]

### ⑦ Ladder algebra
\[
[a,a^\dagger]=I,\qquad N=a^\dagger a,\qquad
N|n\rangle=n|n\rangle,
\]
\[
a|n\rangle=\sqrt n\,|n-1\rangle,\qquad
a^\dagger|n\rangle=\sqrt{n+1}|n+1\rangle.
\]

### ⑧ \(X,P\) in ladder form
Define
\[
\alpha=\sqrt{\frac{\hbar}{2m\omega}},\qquad
\beta=\sqrt{\frac{m\hbar\omega}{2}}=m\omega\alpha.
\]
Then
\[
X=\alpha(a+a^\dagger),
\qquad
P=i\beta(a^\dagger-a).
\]

### ⑨ Useful identities
\[
aa^\dagger=N+I,
\]
\[
H=\hbar\omega\left(N+\frac12\right),
\]
\[
E_n=\hbar\omega\left(n+\frac12\right).
\]

### ⑩ Time evolution
\[
|n,t\rangle=e^{-iE_nt/\hbar}|n\rangle.
\]

### ⑪ Ehrenfest theorem
For \(A\) with no explicit time dependence,
\[
\frac{d}{dt}\langle A\rangle=
\frac{i}{\hbar}\langle[H,A]\rangle.
\]
For the oscillator,
\[
\frac{d}{dt}\langle X\rangle=\frac{\langle P\rangle}{m},
\qquad
\frac{d}{dt}\langle P\rangle=-m\omega^2\langle X\rangle.
\]

### ⑫ Classical circular-orbit relations
\[
T=\frac12mv^2,\qquad
F_r=-\frac{dV}{dr},\qquad
\frac{mv^2}{r}=\left|\frac{dV}{dr}\right|.
\]

### ⑬ Poisson bracket
\[
\{f,g\}_{PB}
=
\frac{\partial f}{\partial x}\frac{\partial g}{\partial p}
-
\frac{\partial f}{\partial p}\frac{\partial g}{\partial x}.
\]

### ⑭ Poisson-bracket / commutator correspondence
If
\[
\{\omega,\lambda\}_{PB}=\chi,
\]
then one expects
\[
[\Omega,\Lambda]=i\hbar\,\widehat{\chi},
\]
subject to possible operator-ordering ambiguity.

# Exercise 7.4.5

## Problem (English)

**At \(t=0\) a particle starts out in**
\[
|\psi(0)\rangle=\frac1{\sqrt2}(|0\rangle+|1\rangle).
\]
**(1) Find \(|\psi(t)\rangle\).  
(2) Find \(\langle X(0)\rangle,\langle P(0)\rangle,\langle X(t)\rangle,\langle P(t)\rangle\).  
(3) Using Ehrenfest's theorem, find the differential equations for \(\langle X(t)\rangle,\langle P(t)\rangle\), solve them, and compare with part (2).**

## Solution

### (1) State evolution

\[
E_0=\frac12\hbar\omega,\qquad
E_1=\frac32\hbar\omega.
\]
Thus
\[
|\psi(t)\rangle
=
\frac1{\sqrt2}
\left(
e^{-i\omega t/2}|0\rangle
+
e^{-i3\omega t/2}|1\rangle
\right).
\]
Equivalently,
\[
\boxed{
|\psi(t)\rangle
=
\frac{e^{-i\omega t/2}}{\sqrt2}
\left(
|0\rangle+e^{-i\omega t}|1\rangle
\right).
}
\]

### (2) Expectation values

Using the matrix elements from 7.4.1,
\[
\langle0|X|1\rangle=\alpha,
\qquad
\langle1|X|0\rangle=\alpha,
\]
so
\[
\boxed{\langle X(0)\rangle=\alpha}.
\]

For momentum,
\[
\langle0|P|1\rangle=-i\beta,
\qquad
\langle1|P|0\rangle=i\beta,
\]
so
\[
\boxed{\langle P(0)\rangle=0}.
\]

At time \(t\), the cross terms give
\[
\boxed{
\langle X(t)\rangle=\alpha\cos\omega t
}
\]
and
\[
\boxed{
\langle P(t)\rangle=-\beta\sin\omega t.
}
\]

### (3) Ehrenfest theorem

From ⑪:
\[
\dot{\langle X\rangle}=\frac{\langle P\rangle}{m},
\qquad
\dot{\langle P\rangle}=-m\omega^2\langle X\rangle.
\]
Therefore
\[
\ddot{\langle X\rangle}+\omega^2\langle X\rangle=0.
\]
With
\[
\langle X(0)\rangle=\alpha,\qquad
\dot{\langle X\rangle}(0)=0,
\]
the solution is
\[
\boxed{
\langle X(t)\rangle=\alpha\cos\omega t.
}
\]
Then
\[
\langle P(t)\rangle
=
m\dot{\langle X\rangle}
=
-m\omega\alpha\sin\omega t
=
\boxed{-\beta\sin\omega t}.
\]

This exactly agrees with part (2).

## Logic chain
\[
\boxed{
⑨+⑩+|\psi(0)\rangle
\Rightarrow
|\psi(t)\rangle
}
\]
\[
\boxed{
|\psi(t)\rangle+7.4.1+②
\Rightarrow
\langle X(t)\rangle,\langle P(t)\rangle
}
\]
\[
\boxed{
⑪
\Rightarrow
\dot{\langle X\rangle}=\langle P\rangle/m,\ 
\dot{\langle P\rangle}=-m\omega^2\langle X\rangle
}
\]
\[
\boxed{
\Rightarrow
\ddot{\langle X\rangle}+\omega^2\langle X\rangle=0
\Rightarrow
\langle X(t)\rangle,\langle P(t)\rangle
}
\]
