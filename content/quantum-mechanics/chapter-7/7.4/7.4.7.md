# Shankar §7.4 Exercises 7.4.1–7.4.7

## Unified prerequisites: inputs not derived inside these exercises

### ① Orthonormal number basis
\[
\langle n'|n\rangle=\delta_{n'n},\qquad n=0,1,2,\ldots
\]

### ② Expectation value and variance
\[
\langle A\rangle=\langle\psi|A|\psi\rangle,\qquad
(\Delta A)^2=\langle A^2\rangle-\langle A\rangle^2.
\]

### ③ Canonical commutator
\[
[X,P]=i\hbar I.
\]

### ④ Commutator identities
\[
[A,B]=AB-BA,
\]
\[
[AB,C]=A[B,C]+[A,C]B,
\]
\[
[A,BC]=[A,B]C+B[A,C].
\]

### ⑤ Harmonic-oscillator Hamiltonian
\[
H=\frac{P^2}{2m}+\frac12m\omega^2X^2.
\]

### ⑥ Ladder operators
\[
a=\sqrt{\frac{m\omega}{2\hbar}}X+
\frac{i}{\sqrt{2m\hbar\omega}}P,
\]
\[
a^\dagger=\sqrt{\frac{m\omega}{2\hbar}}X-
\frac{i}{\sqrt{2m\hbar\omega}}P.
\]

### ⑦ Ladder algebra
\[
[a,a^\dagger]=I,\qquad N=a^\dagger a,\qquad
N|n\rangle=n|n\rangle,
\]
\[
a|n\rangle=\sqrt n\,|n-1\rangle,\qquad
a^\dagger|n\rangle=\sqrt{n+1}|n+1\rangle.
\]

### ⑧ \(X,P\) in ladder form
Define
\[
\alpha=\sqrt{\frac{\hbar}{2m\omega}},\qquad
\beta=\sqrt{\frac{m\hbar\omega}{2}}=m\omega\alpha.
\]
Then
\[
X=\alpha(a+a^\dagger),
\qquad
P=i\beta(a^\dagger-a).
\]

### ⑨ Useful identities
\[
aa^\dagger=N+I,
\]
\[
H=\hbar\omega\left(N+\frac12\right),
\]
\[
E_n=\hbar\omega\left(n+\frac12\right).
\]

### ⑩ Time evolution
\[
|n,t\rangle=e^{-iE_nt/\hbar}|n\rangle.
\]

### ⑪ Ehrenfest theorem
For \(A\) with no explicit time dependence,
\[
\frac{d}{dt}\langle A\rangle=
\frac{i}{\hbar}\langle[H,A]\rangle.
\]
For the oscillator,
\[
\frac{d}{dt}\langle X\rangle=\frac{\langle P\rangle}{m},
\qquad
\frac{d}{dt}\langle P\rangle=-m\omega^2\langle X\rangle.
\]

### ⑫ Classical circular-orbit relations
\[
T=\frac12mv^2,\qquad
F_r=-\frac{dV}{dr},\qquad
\frac{mv^2}{r}=\left|\frac{dV}{dr}\right|.
\]

### ⑬ Poisson bracket
\[
\{f,g\}_{PB}
=
\frac{\partial f}{\partial x}\frac{\partial g}{\partial p}
-
\frac{\partial f}{\partial p}\frac{\partial g}{\partial x}.
\]

### ⑭ Poisson-bracket / commutator correspondence
If
\[
\{\omega,\lambda\}_{PB}=\chi,
\]
then one expects
\[
[\Omega,\Lambda]=i\hbar\,\widehat{\chi},
\]
subject to possible operator-ordering ambiguity.

# Exercise 7.4.7

## Problem (English)

**Verify Eq. (7.4.40) for the cases**
\[
(1)\quad \Omega=X,\qquad \Lambda=X^2+P^2,
\]
\[
(2)\quad \Omega=X^2,\qquad \Lambda=P^2.
\]

**The second case illustrates the ordering ambiguity.**

Eq. (7.4.40) is the classical-to-quantum relation
\[
\{\omega,\lambda\}_{PB}=\chi
\quad\leadsto\quad
[\Omega,\Lambda]=i\hbar\,\widehat\chi,
\]
up to operator-ordering ambiguity.

## Solution: Case (1)

Classically,
\[
\{x,x^2+p^2\}_{PB}
=
1\cdot2p-0
=
\boxed{2p}.
\]

Quantum mechanically,
\[
[X,X^2+P^2]
=
[X,X^2]+[X,P^2].
\]
The first term vanishes. Using ④:
\[
[X,P^2]
=
[X,P]P+P[X,P].
\]
By ③:
\[
[X,P^2]
=
i\hbar P+Pi\hbar
=
2i\hbar P.
\]
Thus
\[
\boxed{
[X,X^2+P^2]=2i\hbar P,
}
\]
which is exactly \(i\hbar\) times the quantization of \(2p\).

## Solution: Case (2)

Classically,
\[
\{x^2,p^2\}_{PB}
=
(2x)(2p)
=
\boxed{4xp}.
\]

Quantum mechanically,
\[
[X^2,P^2]
=
X[X,P^2]+[X,P^2]X.
\]
From case (1),
\[
[X,P^2]=2i\hbar P.
\]
Therefore
\[
\boxed{
[X^2,P^2]
=
2i\hbar(XP+PX).
}
\]

Now the ordering issue appears. Classically,
\[
xp=px,
\]
but quantum mechanically,
\[
XP\neq PX.
\]
Thus the classical object \(4xp\) could be mapped to several quantum operators:
\[
4XP,\qquad4PX,\qquad2(XP+PX),\ldots
\]

If we choose the symmetric prescription
\[
\boxed{
\widehat{4xp}=2(XP+PX),
}
\]
then
\[
\boxed{
[X^2,P^2]
=
i\hbar\,\widehat{4xp}.
}
\]

So the correspondence works, but only after specifying an ordering prescription.

## Logic chain

Case (1):
\[
\boxed{
⑬+x,\ x^2+p^2
\Rightarrow
\{x,x^2+p^2\}_{PB}=2p
}
\]
\[
\boxed{
③+④
\Rightarrow
[X,P^2]=2i\hbar P
}
\]
\[
\boxed{
\Rightarrow
[X,X^2+P^2]=2i\hbar P
}
\]
\[
\boxed{
⑭\Rightarrow\text{agreement}
}
\]

Case (2):
\[
\boxed{
⑬+x^2,p^2
\Rightarrow
\{x^2,p^2\}_{PB}=4xp
}
\]
\[
\boxed{
③+④
\Rightarrow
[X^2,P^2]=2i\hbar(XP+PX)
}
\]
\[
\boxed{
xp=px\text{ classically},\ XP\neq PX\text{ quantum mechanically}
\Rightarrow
\text{ordering ambiguity}
}
\]
\[
\boxed{
\widehat{4xp}=2(XP+PX)
\Rightarrow
[X^2,P^2]=i\hbar\widehat{4xp}
}
\]
