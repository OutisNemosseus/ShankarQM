# Shankar Exercise 7.3.1 — 用矩阵力学重写：公理、假设、定义、推导链

> 目标：不用位置表象中的 power series 作为主要方法，而从矩阵力学出发，把**哪些东西是先验输入、哪些是定义、哪些是由前面推出的结论**全部编号，并明确写成  
>
> \[
> \boxed{①+②\Rightarrow ③}
> \]
>
> 的形式。

---

# 0. 先澄清一个重要点

Shankar 7.3.1 原题讨论的是：在**位置表象**中直接令

\[
\psi(y)=\sum_n C_n y^n
\]

为什么会出现涉及

\[
C_{n+2},\quad C_n,\quad C_{n-2}
\]

的 three-term recursion；而先抽出 Gaussian 后为什么变成 two-term recursion。

如果完全改用矩阵力学，我们可以**绕开这个 power-series recursion，直接求出谐振子的能谱和算符结构**。

但是要注意：

\[
\boxed{
\text{原题中的 }C_n\text{ 是幂级数系数，不是 number-basis 系数。}
}
\]

所以不能把原题的 \(C_{n\pm2}\) 和 \(|n\pm2\rangle\) 简单当成同一个东西。

矩阵力学做的是一个**等价的替代解法**：

\[
\boxed{
\text{不解微分方程}
\;\longrightarrow\;
\text{直接用 }X,P,H\text{ 的代数关系求 spectrum}
}
\]

---

# 1. 必须先知道的输入：到底有几条？

这里分成四类：

- **量子力学公理 / 基本结构**
- **这个物理模型额外给定的假设**
- **定义**
- **之后推出来的结论**

---

# A. 量子力学基本输入

## ① 状态属于 Hilbert space

量子态是 Hilbert space 中的向量：

\[
|\psi\rangle\in\mathcal H.
\]

并且物理态必须有有限范数：

\[
\boxed{
\langle\psi|\psi\rangle<\infty
}
\]

通常归一化为

\[
\boxed{
\langle\psi|\psi\rangle=1.
}
\]

在离散正交基下：

\[
|\psi\rangle=
\begin{pmatrix}
c_0\\c_1\\c_2\\\vdots
\end{pmatrix},
\]

所以

\[
\boxed{
\sum_n |c_n|^2=1.
}
\]

---

## ② 可观测量由 Hermitian operator 表示

位置、动量、能量分别由

\[
X,\qquad P,\qquad H
\]

表示，并满足

\[
X^\dagger=X,\qquad
P^\dagger=P,\qquad
H^\dagger=H.
\]

---

## ③ 正则对易关系

一维量子力学给定

\[
\boxed{
[X,P]=i\hbar I.
}
\]

这是矩阵力学最核心的输入之一。

它不是由 harmonic oscillator 势能推出的。

---

## ④ 能量本征态满足本征值方程

stationary state 满足

\[
\boxed{
H|E\rangle=E|E\rangle.
}
\]

这是 Schrödinger stationary equation 的抽象 Hilbert-space / matrix 形式。

---

# B. 谐振子模型本身额外给定的输入

## ⑤ 谐振子的 Hamiltonian

这不是“量子力学公理”，而是我们对这个具体物理系统的模型：

\[
\boxed{
H=
\frac{P^2}{2m}
+
\frac12m\omega^2X^2.
}
\]

这里

\[
m>0,\qquad \omega>0.
\]

因此整个问题的真正物理输入到这里一共是：

\[
\boxed{①,②,③,④,⑤}
\]

其中：

- ①–④：量子力学的一般结构；
- ⑤：harmonic oscillator 这个具体系统的 Hamiltonian。

---

# C. 下面不是公理，而是我们主动做的定义

## ⑥ 定义 lowering operator

\[
\boxed{
a=
\sqrt{\frac{m\omega}{2\hbar}}X
+
\frac{i}{\sqrt{2m\hbar\omega}}P
}
\]

---

## ⑦ 定义 raising operator

\[
\boxed{
a^\dagger=
\sqrt{\frac{m\omega}{2\hbar}}X
-
\frac{i}{\sqrt{2m\hbar\omega}}P.
}
\]

因为 ② 中 \(X,P\) 都是 Hermitian，所以这个符号确实满足

\[
(a)^\dagger=a^\dagger.
\]

也就是：

\[
\boxed{②+⑥\Rightarrow⑦\text{ 的确是 }⑥\text{ 的 Hermitian conjugate}.}
\]

---

# 2. 第一步推导：由 ③、⑥、⑦ 得到 ladder algebra

我们计算

\[
[a,a^\dagger].
\]

设

\[
\alpha=\sqrt{\frac{m\omega}{2\hbar}},
\qquad
\beta=\frac1{\sqrt{2m\hbar\omega}}.
\]

那么

\[
a=\alpha X+i\beta P,
\qquad
a^\dagger=\alpha X-i\beta P.
\]

所以

\[
[a,a^\dagger]
=
[\alpha X+i\beta P,\alpha X-i\beta P].
\]

利用

\[
[X,X]=0,\qquad[P,P]=0
\]

以及 ③：

\[
[X,P]=i\hbar I,
\]

得到

\[
[a,a^\dagger]
=
-\,i\alpha\beta[X,P]
+i\alpha\beta[P,X].
\]

而

\[
[P,X]=-[X,P]=-i\hbar I.
\]

因此

\[
[a,a^\dagger]
=
2\alpha\beta\hbar I.
\]

又因为

\[
2\alpha\beta\hbar=1,
\]

所以得到：

\[
\boxed{
⑧\qquad [a,a^\dagger]=I.
}
\]

推导链：

\[
\boxed{
③+⑥+⑦
\Rightarrow
⑧
}
\]

---

# 3. 第二步：由 Hamiltonian ⑤ 改写成 \(a,a^\dagger\)

由 ⑥、⑦ 相加：

\[
a+a^\dagger
=
2\sqrt{\frac{m\omega}{2\hbar}}X.
\]

因此

\[
\boxed{
⑨\qquad
X=
\sqrt{\frac{\hbar}{2m\omega}}
(a+a^\dagger).
}
\]

推导链：

\[
\boxed{
⑥+⑦\Rightarrow⑨
}
\]

同样两式相减：

\[
a-a^\dagger
=
\frac{2i}{\sqrt{2m\hbar\omega}}P.
\]

所以

\[
\boxed{
⑩\qquad
P=
-i\sqrt{\frac{m\hbar\omega}{2}}
(a-a^\dagger).
}
\]

推导链：

\[
\boxed{
⑥+⑦\Rightarrow⑩
}
\]

---

# 4. 第三步：代回 Hamiltonian

由 ⑤：

\[
H=
\frac{P^2}{2m}
+
\frac12m\omega^2X^2.
\]

使用 ⑨：

\[
\frac12m\omega^2X^2
=
\frac{\hbar\omega}{4}
(a+a^\dagger)^2.
\]

使用 ⑩：

\[
\frac{P^2}{2m}
=
-\frac{\hbar\omega}{4}
(a-a^\dagger)^2.
\]

所以

\[
H
=
\frac{\hbar\omega}{4}
\left[
(a+a^\dagger)^2-(a-a^\dagger)^2
\right].
\]

展开：

\[
(a+a^\dagger)^2
=
a^2+aa^\dagger+a^\dagger a+(a^\dagger)^2,
\]

\[
(a-a^\dagger)^2
=
a^2-aa^\dagger-a^\dagger a+(a^\dagger)^2.
\]

相减以后

\[
a^2,\qquad (a^\dagger)^2
\]

完全抵消，因此

\[
H=
\frac{\hbar\omega}{2}
(aa^\dagger+a^\dagger a).
\]

利用 ⑧：

\[
aa^\dagger=a^\dagger a+I.
\]

所以

\[
\boxed{
⑪\qquad
H=
\hbar\omega
\left(
a^\dagger a+\frac12I
\right).
}
\]

推导链：

\[
\boxed{
⑤+⑧+⑨+⑩
\Rightarrow
⑪
}
\]

这是整个矩阵力学解法最关键的一步。

---

# 5. 第四步：定义 number operator

定义

\[
\boxed{
⑫\qquad
N=a^\dagger a.
}
\]

注意：⑫是定义，不是公理。

由 ⑪：

\[
\boxed{
⑬\qquad
H=
\hbar\omega
\left(
N+\frac12I
\right).
}
\]

推导链：

\[
\boxed{
⑪+⑫
\Rightarrow
⑬
}
\]

---

# 6. 第五步：为什么 \(N\) 的本征值不能是负数？

假设

\[
N|\lambda\rangle
=
\lambda|\lambda\rangle.
\]

取 expectation value：

\[
\langle\lambda|N|\lambda\rangle
=
\lambda
\langle\lambda|\lambda\rangle.
\]

由 ⑫：

\[
N=a^\dagger a.
\]

因此

\[
\langle\lambda|N|\lambda\rangle
=
\langle\lambda|a^\dagger a|\lambda\rangle.
\]

利用 Hilbert-space 内积：

\[
\langle\lambda|a^\dagger a|\lambda\rangle
=
\langle a\lambda|a\lambda\rangle
=
\|a|\lambda\rangle\|^2.
\]

根据 ①，范数平方不能为负：

\[
\|a|\lambda\rangle\|^2\ge0.
\]

因此

\[
\boxed{
⑭\qquad
\lambda\ge0.
}
\]

推导链：

\[
\boxed{
①+⑫
\Rightarrow
⑭
}
\]

这一步非常重要：

\[
\boxed{
N\ge0
}
\]

不是额外假设，而是由 Hilbert-space norm 自动推出的。

---

# 7. 第六步：证明 \(a\) 会把 \(N\) 的本征值降低 1

由 ⑧：

\[
[a,a^\dagger]=I.
\]

由 ⑫：

\[
N=a^\dagger a.
\]

计算

\[
[N,a].
\]

有

\[
[N,a]
=
a^\dagger aa-aa^\dagger a.
\]

使用

\[
aa^\dagger=a^\dagger a+I,
\]

得到

\[
[N,a]
=
a^\dagger a^2-(a^\dagger a+I)a
=
-a.
\]

所以

\[
\boxed{
⑮\qquad
[N,a]=-a.
}
\]

推导链：

\[
\boxed{
⑧+⑫\Rightarrow⑮
}
\]

现在假设

\[
N|\lambda\rangle=\lambda|\lambda\rangle.
\]

那么

\[
N(a|\lambda\rangle)
=
(aN+[N,a])|\lambda\rangle.
\]

使用 ⑮：

\[
N(a|\lambda\rangle)
=
a\lambda|\lambda\rangle-a|\lambda\rangle.
\]

所以

\[
\boxed{
N(a|\lambda\rangle)
=
(\lambda-1)a|\lambda\rangle.
}
\]

因此，只要

\[
a|\lambda\rangle\neq0,
\]

它就是新的本征态，其 eigenvalue 是

\[
\lambda-1.
\]

也就是：

\[
\boxed{
⑯\qquad
a:\lambda\mapsto\lambda-1.
}
\]

推导链：

\[
\boxed{
④+⑮
\Rightarrow
⑯
}
\]

这里④更准确地说是“我们考虑 operator 的 eigenstate”；同样的 eigenvector 逻辑适用于 \(N\)。

---

# 8. 第七步：为什么下降一定会停止？

如果一直作用 \(a\)：

\[
|\lambda\rangle
\to
a|\lambda\rangle
\to
a^2|\lambda\rangle
\to\cdots
\]

对应 eigenvalue：

\[
\lambda,\quad
\lambda-1,\quad
\lambda-2,\quad\ldots
\]

但是由 ⑭：

\[
\lambda\ge0.
\]

所以不能最终得到负 eigenvalue。

因此必定存在某个最低态 \(|0\rangle\)，使得

\[
\boxed{
⑰\qquad
a|0\rangle=0.
}
\]

而这时

\[
N|0\rangle
=
a^\dagger a|0\rangle
=0.
\]

所以：

\[
\boxed{
N|0\rangle=0.
}
\]

推导链：

\[
\boxed{
⑭+⑯
\Rightarrow
⑰
}
\]

因此最低 number eigenvalue 是

\[
\boxed{0}.
\]

---

# 9. 第八步：raising operator

类似计算：

\[
[N,a^\dagger]
=
a^\dagger.
\]

所以得到

\[
\boxed{
⑱\qquad
[N,a^\dagger]=a^\dagger.
}
\]

推导链：

\[
\boxed{
⑧+⑫
\Rightarrow
⑱
}
\]

若

\[
N|n\rangle=n|n\rangle,
\]

那么

\[
N(a^\dagger|n\rangle)
=
(n+1)a^\dagger|n\rangle.
\]

所以

\[
\boxed{
⑲\qquad
a^\dagger:n\mapsto n+1.
}
\]

推导链：

\[
\boxed{
⑱+\text{eigenvalue equation}
\Rightarrow
⑲
}
\]

于是所有允许的 number eigenvalues 是

\[
\boxed{
n=0,1,2,3,\ldots
}
\]

---

# 10. 第九步：推出能量

由 ⑬：

\[
H=
\hbar\omega
\left(
N+\frac12I
\right).
\]

又有

\[
N|n\rangle=n|n\rangle.
\]

所以

\[
H|n\rangle
=
\hbar\omega
\left(
n+\frac12
\right)|n\rangle.
\]

因此：

\[
\boxed{
⑳\qquad
E_n=
\hbar\omega
\left(
n+\frac12
\right).
}
\]

推导链：

\[
\boxed{
⑬+⑰+⑲
\Rightarrow
⑳
}
\]

注意：

\[
\boxed{
E_n\text{ 的离散化不是额外公理。}
}
\]

它是由前面的结构推出来的。

---

# 11. 第十步：现在才选择 number basis，并写出矩阵

选择

\[
\{|0\rangle,|1\rangle,|2\rangle,\ldots\}
\]

作为 basis。

则

\[
|0\rangle=
\begin{pmatrix}
1\\0\\0\\0\\\vdots
\end{pmatrix},
\qquad
|1\rangle=
\begin{pmatrix}
0\\1\\0\\0\\\vdots
\end{pmatrix},
\qquad
|2\rangle=
\begin{pmatrix}
0\\0\\1\\0\\\vdots
\end{pmatrix}.
\]

由 ladder relation：

\[
a|n\rangle=\sqrt n|n-1\rangle,
\]

\[
a^\dagger|n\rangle=\sqrt{n+1}|n+1\rangle.
\]

于是

\[
\boxed{
a=
\begin{pmatrix}
0&1&0&0&0&\cdots\\
0&0&\sqrt2&0&0&\cdots\\
0&0&0&\sqrt3&0&\cdots\\
0&0&0&0&2&\cdots\\
\vdots&&&&\ddots
\end{pmatrix}
}
\]

以及

\[
\boxed{
a^\dagger=
\begin{pmatrix}
0&0&0&0&\cdots\\
1&0&0&0&\cdots\\
0&\sqrt2&0&0&\cdots\\
0&0&\sqrt3&0&\cdots\\
\vdots&&&&\ddots
\end{pmatrix}.
}
\]

因此

\[
N=a^\dagger a
=
\boxed{
\begin{pmatrix}
0&0&0&0&\cdots\\
0&1&0&0&\cdots\\
0&0&2&0&\cdots\\
0&0&0&3&\cdots\\
\vdots&&&&\ddots
\end{pmatrix}
}.
\]

最后

\[
\boxed{
H=
\hbar\omega
\begin{pmatrix}
\frac12&0&0&0&\cdots\\
0&\frac32&0&0&\cdots\\
0&0&\frac52&0&\cdots\\
0&0&0&\frac72&\cdots\\
\vdots&&&&\ddots
\end{pmatrix}.
}
\]

# 12. \(X\) 和 \(P\) 的矩阵

由 ⑨：

\[
X=
\sqrt{\frac{\hbar}{2m\omega}}
(a+a^\dagger),
\]

所以

\[
\boxed{
X=
\sqrt{\frac{\hbar}{2m\omega}}
\begin{pmatrix}
0&1&0&0&\cdots\\

}
\]

\[
P=
-i\sqrt{\frac{m\hbar\omega}{2}}

\]

所以

\[
\boxed{
P=
i\sqrt{\frac{m\hbar\omega}{2}}
\begin{pmatrix}
0&-1&0&0&\cdots\\
1&0&-\sqrt2&0&\cdots\\
0&\sqrt2&0&-\sqrt3&\cdots\\
0&0&\sqrt3&0&\cdots\\

\end{pmatrix}.
}
\]

# 13. 为什么 \(X^2\) 出现 \(n,n\pm2\) coupling？

由

\[
X=
\sqrt{\frac{\hbar}{2m\omega}}
(a+a^\dagger),
\]

所以

\[
X^2
=
\frac{\hbar}{2m\omega}
\left[
a^2+aa^\dagger+a^\dagger a+(a^\dagger)^2
\right].
\]

因此

\[
X^2|n\rangle
=
\frac{\hbar}{2m\omega}
\left[
\sqrt{n(n-1)}|n-2\rangle
+
(2n+1)|n\rangle
+
\sqrt{(n+1)(n+2)}|n+2\rangle
\right].
\]

所以：

\[
\boxed{
㉑\qquad
X^2:
|n\rangle
\to
|n-2\rangle,\ |n\rangle,\ |n+2\rangle.
}
\]

推导链：

\[
\boxed{
⑨+⑧
\Rightarrow
㉑
}
\]

矩阵为

\[
\boxed{
X^2=
\frac{\hbar}{2m\omega}
\begin{pmatrix}
1&0&\sqrt2&0&\cdots\\
0&3&0&\sqrt6&\cdots\\
\sqrt2&0&5&0&2\sqrt3&\cdots\\
0&\sqrt6&0&7&\cdots\\
\vdots&&&&\ddots
\end{pmatrix}.
}
\]

# 14. \(P^2\) 的非对角项为什么正好相反？

由 ⑩：

\[
P=
-i\sqrt{\frac{m\hbar\omega}{2}}
(a-a^\dagger).
\]

所以

\[
P^2
=
-\frac{m\hbar\omega}{2}
(a-a^\dagger)^2.
\]

因此

\[
P^2|n\rangle
=
\frac{m\hbar\omega}{2}
\left[
-\sqrt{n(n-1)}|n-2\rangle
+
(2n+1)|n\rangle
-
\sqrt{(n+1)(n+2)}|n+2\rangle
\right].
\]

矩阵：

\[
\boxed{
P^2=
\frac{m\hbar\omega}{2}
\begin{pmatrix}
1&0&-\sqrt2&0&\cdots\\
0&3&0&-\sqrt6&\cdots\\
-\sqrt2&0&5&0&-2\sqrt3&\cdots\\
0&-\sqrt6&0&7&\cdots\\
\vdots&&&&\ddots
\end{pmatrix}.
}
\]

所以：

\[
\boxed{
㉒\qquad
P^2\text{ 的 }n\leftrightarrow n\pm2
\text{ 项与 }X^2\text{ 符号相反。}
}
\]

推导链：

\[
\boxed{
⑩+⑧
\Rightarrow
㉒
}
\]

# 15. 为什么 Hamiltonian 最终对角化？

由 ⑤：

\[
H=
\frac{P^2}{2m}
+
\frac12m\omega^2X^2.
\]

potential matrix：

\[
\frac12m\omega^2X^2
=
\frac{\hbar\omega}{4}
\begin{pmatrix}
1&0&+\sqrt2&0&\cdots\\
0&3&0&+\sqrt6&\cdots\\
+\sqrt2&0&5&0&\cdots\\
0&+\sqrt6&0&7&\cdots\\
\vdots&&&&\ddots
\end{pmatrix}.
\]

kinetic matrix：

\[
\frac{P^2}{2m}
=
\frac{\hbar\omega}{4}
\begin{pmatrix}
1&0&-\sqrt2&0&\cdots\\
0&3&0&-\sqrt6&\cdots\\
-\sqrt2&0&5&0&\cdots\\
0&-\sqrt6&0&7&\cdots\\
\vdots&&&&\ddots
\end{pmatrix}.
\]

相加：

\[
+\sqrt2+(-\sqrt2)=0,
\]

\[
+\sqrt6+(-\sqrt6)=0,
\]

等等。

所以所有 \(n\pm2\) off-diagonal elements 消失：

\[
\boxed{
㉓\qquad
H=
\hbar\omega
\operatorname{diag}
\left(
\frac12,\frac32,\frac52,\frac72,\ldots
\right).
}
\]

推导链：

\[
\boxed{
⑤+㉑+㉒
\Rightarrow
㉓
}
\]

# 16. 这和 Shankar 7.3.1 到底是什么关系？

原题在 position representation 中写：

\[
\psi''(y)+(2\epsilon-y^2)\psi(y)=0.
\]

若直接令

\[
\psi(y)=\sum_n C_n y^n,
\]

那么：

- \(\psi''\) 把 power \(n+2\) 降到 \(n\)；
- \(2\epsilon\psi\) 保持 power \(n\)；
- \(y^2\psi\) 把 power \(n-2\) 升到 \(n\)。

于是得到

\[
C_{n+2},\qquad C_n,\qquad C_{n-2}.
\]

这就是原题的 three-term recursion。

矩阵力学则不使用 monomial basis

\[
1,y,y^2,y^3,\ldots
\]

而是找到 Hamiltonian 的自然 basis：

\[
|0\rangle,|1\rangle,|2\rangle,\ldots
\]

在这个 basis 里，Hamiltonian 已经是 diagonal。

因此两种方法的关系是：

\[
\boxed{
\begin{array}{ccc}
\text{位置表象}
&&
\text{矩阵力学}
\\[2mm]
\text{不自然的 power basis}
&&
\text{energy/number basis}
\\[2mm]
C_{n-2},C_n,C_{n+2}
&&
H=\text{diagonal}
\end{array}
}
\]

# 17. Gaussian \(e^{-y^2/2}\) 在矩阵力学里去哪里了？

它不是新的公理。

在 number basis 里 ground state 是

\[
|0\rangle=
\begin{pmatrix}
1\\0\\0\\\vdots
\end{pmatrix}.
\]

如果换到 position basis：

\[
\psi_0(x)=\langle x|0\rangle,
\]

再利用

\[
a|0\rangle=0
\]

和 position representation 中

\[
P=-i\hbar\frac{d}{dx},
\]

才会得到

\[
\psi_0(x)
\propto
e^{-m\omega x^2/(2\hbar)}.
\]

所以

\[
\boxed{
e^{-y^2/2}
}
\]

是同一个 ground-state vector 在 position basis 中的函数形式。

# 19. 最少必须背下来的东西

如果目标只是知道“哪些不能从这道题里自己推出”，最少是下面 **5 条输入**：

\[
\boxed{
\begin{aligned}
①\;& |\psi\rangle\in\mathcal H,\quad \langle\psi|\psi\rangle<\infty,\\
②\;& X,P,H\text{ 是 Hermitian operators},\\
③\;& [X,P]=i\hbar I,\\
④\;& H|E\rangle=E|E\rangle,\\
⑤\;& H=\frac{P^2}{2m}+\frac12m\omega^2X^2.
\end{aligned}
}
\]

其余关键结论：

\[
[a,a^\dagger]=1,
\]

\[
H=\hbar\omega(a^\dagger a+\tfrac12),
\]

\[
N\ge0,
\]

\[
a|n\rangle\propto|n-1\rangle,
\]

\[
a^\dagger|n\rangle\propto|n+1\rangle,
\]

\[
n=0,1,2,\ldots,
\]

\[
E_n=\hbar\omega(n+\tfrac12)
\]

全部可以从这 5 条输入加上 \(a,a^\dagger,N\) 的定义推出来。

# 20. 一句话理解 Exercise 7.3.1 的矩阵版本

\[
\boxed{
\text{原题的复杂 recursion 不是新的物理，
而是 representation / basis 选择带来的计算复杂度。}
}
\]

在 position-power basis 中：

\[
C_{n-2},C_n,C_{n+2}
\]

互相耦合。

在 harmonic oscillator 的自然 number basis 中：

\[
\boxed{
H=
\hbar\omega
\operatorname{diag}
\left(
\frac12,\frac32,\frac52,\ldots
\right),
}
\]

问题直接变成一个对角矩阵的本征值问题。
