# Shankar Harmonic Oscillator — 传统微分方程解法：公理、假设、定义、推导链

> 目标：把 harmonic oscillator 的传统 differential-equation 解法，按照
>
> \[
> \boxed{①+②\Rightarrow③}
> \]
>
> 的方式整理出来，明确区分：
>
> - 哪些是量子力学的基本输入；
> - 哪些是 harmonic oscillator 这个模型本身的输入；
> - 哪些是人为定义；
> - 哪些是后面真正推出来的结论。

---

# 1. 最开始必须知道的输入

## ① Hilbert-space / normalizability 条件

量子态必须属于 Hilbert space：

\[
|\psi\rangle\in\mathcal H.
\]

在 position representation 中：

\[
\psi(x)=\langle x|\psi\rangle.
\]

物理束缚态必须满足

\[
\boxed{
\int_{-\infty}^{\infty}|\psi(x)|^2dx<\infty
}
\]

并且可以归一化为

\[
\boxed{
\int_{-\infty}^{\infty}|\psi(x)|^2dx=1.
}
\]

这一步是后面排除发散解的根本物理条件。

---

## ② Position-space 中的动量算符

在 position representation 中：

\[
\boxed{
P=-i\hbar\frac{d}{dx}.
}
\]

所以

\[
P^2
=
-\hbar^2\frac{d^2}{dx^2}.
\]

---

## ③ Stationary Schrödinger equation

能量本征态满足

\[
\boxed{
H\psi(x)=E\psi(x).
}
\]

---

## ④ Harmonic oscillator 的 Hamiltonian

这个具体物理模型给定：

\[
\boxed{
H=
\frac{P^2}{2m}
+
\frac12m\omega^2x^2.
}
\]

这里

\[
m>0,\qquad \omega>0.
\]

---

# 2. 从 ②+③+④ 得到微分方程

由

\[
P^2
=
-\hbar^2\frac{d^2}{dx^2}
\]

以及

\[
H=
\frac{P^2}{2m}
+
\frac12m\omega^2x^2
\]

代入

\[
H\psi=E\psi,
\]

得到

\[
-\frac{\hbar^2}{2m}\psi''(x)
+
\frac12m\omega^2x^2\psi(x)
=
E\psi(x).
\]

所以：

\[
\boxed{
⑤\qquad
-\frac{\hbar^2}{2m}\psi''
+
\frac12m\omega^2x^2\psi
=
E\psi.
}
\]

推导链：

\[
\boxed{
②+③+④
\Rightarrow
⑤
}
\]

---

# 3. 无量纲化

定义新的无量纲变量：

\[
\boxed{
⑥\qquad
y=\sqrt{\frac{m\omega}{\hbar}}\,x
}
\]

以及

\[
\boxed{
⑦\qquad
\epsilon=\frac{E}{\hbar\omega}.
}
\]

因为

\[
\frac{d}{dx}
=
\sqrt{\frac{m\omega}{\hbar}}
\frac{d}{dy},
\]

所以

\[
\frac{d^2}{dx^2}
=
\frac{m\omega}{\hbar}
\frac{d^2}{dy^2}.
\]

把这些代回 ⑤，得到

\[
-\frac12\psi''(y)
+
\frac12y^2\psi(y)
=
\epsilon\psi(y).
\]

乘以 2：

\[
-\psi''+y^2\psi=2\epsilon\psi.
\]

整理：

\[
\boxed{
⑧\qquad
\psi''(y)+(2\epsilon-y^2)\psi(y)=0.
}
\]

推导链：

\[
\boxed{
⑤+⑥+⑦
\Rightarrow
⑧
}
\]

这就是 Shankar 原来的 Eq. (7.3.8) 类型的方程。

---

# 4. 先看大 \(|y|\) 时的行为

当

\[
|y|\to\infty
\]

时，

\[
y^2\gg 2\epsilon.
\]

所以 ⑧ 近似为

\[
\psi''-y^2\psi\approx0.
\]

我们寻找指数型 asymptotic solution：

\[
\psi(y)\sim e^{f(y)}.
\]

则

\[
\psi'
=f'e^f,
\]

\[
\psi''
=
(f''+f'^2)e^f.
\]

在大 \(|y|\) 下，主导项要求

\[
f'^2\sim y^2.
\]

所以

\[
f'\sim\pm y.
\]

积分得到

\[
f\sim\pm\frac{y^2}{2}.
\]

因此

\[
\boxed{
⑨\qquad
\psi(y)\sim e^{-y^2/2}
\quad\text{或}\quad
e^{+y^2/2}.
}
\]

推导链：

\[
\boxed{
⑧+\text{large-}|y|\text{ approximation}
\Rightarrow
⑨
}
\]

---

# 5. 用 Hilbert-space 条件排除发散解

由 ①：

\[
\int |\psi(y)|^2dy<\infty.
\]

如果取

\[
\psi\sim e^{+y^2/2},
\]

则

\[
|\psi|^2\sim e^{y^2},
\]

于是

\[
\int_{-\infty}^{\infty}e^{y^2}dy
\]

发散。

所以这个解不属于 \(L^2\)。

因此只能保留

\[
\boxed{
⑩\qquad
\psi(y)\sim e^{-y^2/2}.
}
\]

推导链：

\[
\boxed{
①+⑨
\Rightarrow
⑩
}
\]

这一步是传统解法里最重要的物理筛选。

---

# 6. 把已知的 asymptotic behavior 提出来

因为已经知道波函数远处一定包含

\[
e^{-y^2/2},
\]

所以定义

\[
\boxed{
⑪\qquad
\psi(y)=e^{-y^2/2}H(y).
}
\]

这里 \(H(y)\) 是新的未知函数。

这是定义 / ansatz，不是新的物理公理。

---

# 7. 把 ⑪ 代回 ⑧

先算一阶导数：

\[
\psi'
=
e^{-y^2/2}
(H'-yH).
\]

再算二阶导数：

\[
\psi''
=
e^{-y^2/2}
\left[
H''-2yH'+(y^2-1)H
\right].
\]

代入

\[
\psi''+(2\epsilon-y^2)\psi=0.
\]

得到

\[
e^{-y^2/2}
\left[
H''-2yH'+(y^2-1)H
+
(2\epsilon-y^2)H
\right]
=0.
\]

\(y^2H\) 抵消：

\[
H''-2yH'+(2\epsilon-1)H=0.
\]

所以：

\[
\boxed{
⑫\qquad
H''-2yH'+(2\epsilon-1)H=0.
}
\]

推导链：

\[
\boxed{
⑧+⑪
\Rightarrow
⑫
}
\]

这就是 Shankar 变换后的 Eq. (7.3.11) 类型方程。

---

# 8. 现在才做 power-series expansion

定义

\[
\boxed{
⑬\qquad
H(y)=\sum_{n=0}^{\infty}C_n y^n.
}
\]

于是

\[
H'
=
\sum_{n=1}^{\infty}
nC_n y^{n-1},
\]

\[
H''
=
\sum_{n=2}^{\infty}
n(n-1)C_n y^{n-2}.
\]

把 \(H''\) 重编号：

\[
H''
=
\sum_{n=0}^{\infty}
(n+2)(n+1)C_{n+2}y^n.
\]

同时：

\[
-2yH'
=
-2\sum_{n=0}^{\infty}nC_n y^n.
\]

以及

\[
(2\epsilon-1)H
=
\sum_{n=0}^{\infty}
(2\epsilon-1)C_ny^n.
\]

代入 ⑫：

\[
\sum_{n=0}^{\infty}
\left[
(n+2)(n+1)C_{n+2}
+
(2\epsilon-1-2n)C_n
\right]y^n
=
0.
\]

所以每个幂次系数都必须为 0：

\[
(n+2)(n+1)C_{n+2}
+
(2\epsilon-1-2n)C_n
=
0.
\]

因此得到：

\[
\boxed{
⑭\qquad
C_{n+2}
=
\frac{2n+1-2\epsilon}
{(n+2)(n+1)}
C_n.
}
\]

推导链：

\[
\boxed{
⑫+⑬
\Rightarrow
⑭
}
\]

这是 two-term recursion。

---

# 9. 为什么原始方程直接 power series 会得到 three-term recursion？

现在回答 Exercise 7.3.1 本身。

如果不先做 ⑪，而是直接对 ⑧ 假设

\[
\boxed{
⑮\qquad
\psi(y)=\sum_{n=0}^{\infty}C_n y^n,
}
\]

那么：

\[
\psi''
=
\sum_{n=0}^{\infty}
(n+2)(n+1)C_{n+2}y^n.
\]

还有

\[
2\epsilon\psi
=
\sum_{n=0}^{\infty}
2\epsilon C_n y^n.
\]

而

\[
-y^2\psi
=
-\sum_{n=0}^{\infty}C_n y^{n+2}.
\]

为了写成同一个 \(y^n\)，重编号：

\[
-y^2\psi
=
-\sum_{n=2}^{\infty}C_{n-2}y^n.
\]

所以 ⑧ 给出：

\[
(n+2)(n+1)C_{n+2}
+
2\epsilon C_n
-
C_{n-2}
=
0.
\]

即：

\[
\boxed{
⑯\qquad
C_{n+2}
=
\frac{C_{n-2}-2\epsilon C_n}
{(n+2)(n+1)}.
}
\]

推导链：

\[
\boxed{
⑧+⑮
\Rightarrow
⑯
}
\]

这就是 Exercise 7.3.1 要你验证的 three-term recursion：

\[
\boxed{
C_{n+2},\quad C_n,\quad C_{n-2}.
}
\]

---

# 10. 为什么 ⑭ 比 ⑯ 容易？

⑯：

\[
C_{n+2}
\]

同时依赖

\[
C_n
\]

和

\[
C_{n-2}.
\]

所以三个不同层级互相耦合。

而 ⑭：

\[
C_{n+2}
=
f(n,\epsilon)C_n.
\]

只依赖前两个幂次的同 parity 系数。

因此：

- even coefficients 自己形成一条链；
- odd coefficients 自己形成一条链。

例如：

\[
C_0\to C_2\to C_4\to\cdots
\]

以及

\[
C_1\to C_3\to C_5\to\cdots.
\]

所以：

\[
\boxed{
⑭\text{ 比 }⑯\text{ 更容易迭代。}
}
\]

---

# 11. 为什么 series 必须终止？

看 ⑭：

\[
C_{n+2}
=
\frac{2n+1-2\epsilon}
{(n+2)(n+1)}
C_n.
\]

如果 series 永远不终止，那么高阶系数会使 \(H(y)\) 的 asymptotic behavior 最终近似

\[
H(y)\sim e^{y^2}.
\]

于是

\[
\psi(y)
=
e^{-y^2/2}H(y)
\sim
e^{+y^2/2}.
\]

这又违反 ① 的 normalizability。

所以 series 必须在某个 \(n=N\) 终止。

也就是必须有

\[
C_{N+2}=0
\]

而

\[
C_N\neq0.
\]

根据 ⑭，必须满足

\[
2N+1-2\epsilon=0.
\]

所以

\[
\boxed{
⑰\qquad
\epsilon=N+\frac12.
}
\]

推导链：

\[
\boxed{
①+⑩+⑭
\Rightarrow
⑰
}
\]

---

# 12. 推出离散能量

由 ⑦：

\[
\epsilon=\frac{E}{\hbar\omega}.
\]

由 ⑰：

\[
\epsilon=N+\frac12.
\]

所以

\[
\boxed{
⑱\qquad
E_N
=
\hbar\omega
\left(
N+\frac12
\right),
\qquad
N=0,1,2,\ldots
}
\]

推导链：

\[
\boxed{
⑦+⑰
\Rightarrow
⑱
}
\]

这就是 harmonic oscillator energy spectrum。

---

# 13. Hermite polynomial 从哪里出来？

一旦 series 在 \(N\) 阶终止，

\[
H(y)
\]

就成为一个 \(N\) 次 polynomial。

这些 polynomial 正是 Hermite polynomials：

\[
\boxed{
⑲\qquad
H_N(y)\propto \text{Hermite polynomial}.
}
\]

所以最终波函数：

\[
\boxed{
⑳\qquad
\psi_N(y)
=
A_N
H_N(y)e^{-y^2/2}.
}
\]

推导链：

\[
\boxed{
⑪+⑭+⑰
\Rightarrow
⑲
\Rightarrow
⑳
}
\]

---

# 14. 整个 differential-equation 解法的依赖图

\[
\boxed{
\begin{array}{c}
①\ \psi\in L^2
\qquad
②\ P=-i\hbar \frac{d}{dx}
\qquad
③\ H\psi=E\psi
\\[2mm]
④\ H=\frac{P^2}{2m}+\frac12m\omega^2x^2
\\[3mm]
\downarrow
\\[3mm]
②+③+④
\Rightarrow
⑤\ \text{Schrödinger ODE}
\\[3mm]
⑤+⑥+⑦
\Rightarrow
⑧\ \psi''+(2\epsilon-y^2)\psi=0
\\[3mm]
⑧
\Rightarrow
⑨\ \psi\sim e^{\pm y^2/2}
\\[3mm]
①+⑨
\Rightarrow
⑩\ \psi\sim e^{-y^2/2}
\\[3mm]
⑪\ \psi=e^{-y^2/2}H
\\[3mm]
⑧+⑪
\Rightarrow
⑫\ H''-2yH'+(2\epsilon-1)H=0
\\[3mm]
⑫+⑬
\Rightarrow
⑭\ C_{n+2}=f(n,\epsilon)C_n
\\[3mm]
①+⑩+⑭
\Rightarrow
⑰\ \epsilon=n+\frac12
\\[3mm]
⑦+⑰
\Rightarrow
\boxed{
E_n=\hbar\omega\left(n+\frac12\right)
}
\end{array}
}
\]

# 15. Exercise 7.3.1 本身的专门逻辑图

如果只回答 7.3.1，不需要把整个 spectrum 都推完。

题目真正要求的逻辑是：

\[
\boxed{
⑧
+
\psi=\sum C_ny^n
\Rightarrow
C_{n+2},C_n,C_{n-2}
\text{ three-term recursion}
}
\]

具体：

\[
\boxed{
C_{n+2}
=
\frac{C_{n-2}-2\epsilon C_n}
{(n+2)(n+1)}.
}
\]

而先提取 Gaussian：

\[
\boxed{
\psi=e^{-y^2/2}H
}
\]

得到

\[
H''-2yH'+(2\epsilon-1)H=0,
\]

再令

\[
H=\sum C_ny^n,
\]

则

\[
\boxed{
C_{n+2}
=
\frac{2n+1-2\epsilon}
{(n+2)(n+1)}C_n.
}
\]

所以 7.3.1 的最终结论是：

\[
\boxed{
\text{先利用物理 asymptotic condition 抽出 Gaussian，
会把 three-term recursion 简化成 two-term recursion。}
}
\]

# 16. 和矩阵力学版本并排比较

## Differential-equation 路线

\[
\boxed{
H
\to
\text{position representation}
\to
\text{ODE}
\to
\text{asymptotic behavior}
\to
\text{power series}
\to
\text{recursion}
\to
E_n
}
\]

## Matrix-mechanics 路线

\[
\boxed{
H
\to
[X,P]
\to
a,a^\dagger
\to
N=a^\dagger a
\to
H=\hbar\omega(N+\tfrac12)
\to
E_n
}
\]

两条路线最后得到完全相同的：

\[
\boxed{
E_n=\hbar\omega\left(n+\frac12\right).
}
\]

但传统 differential-equation 方法还会直接给出：

\[
\boxed{
\psi_n(x)
}
\]

的空间函数形式；而矩阵力学路线则更直接地揭示 energy ladder 的代数结构。
